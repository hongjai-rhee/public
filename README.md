### 📝 책의 독자를 위한 파일 저장소입니다.

다음 파일들이 저장되어 있으며 필요에 따라 수정/보완됩니다. 
> [!IMPORTANT]
> 
> **/notebook** 장별 노트북 파일: (예) 노트북_23장.ipynb, 책의 실습 코드와 토픽별로 선별된 유튜브 링크 및 보충 자료
> 
> **/exercise** 장별 되새김 문제 정답 파일: (예) 문제_23장.ipynb
> 
> **/data** 실습 데이터: (예) 자동차.csv, soybean_npz

이 저장소의 모든 파일들은 출판사 자료실에서도 다운로드할 수 있습니다.
