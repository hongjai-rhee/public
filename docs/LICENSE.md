# 라이선스 안내 (License)

이 저장소의 실습 코드와 직접 제작한 예제 데이터는 학습 및 교육 목적으로 자유롭게 사용할 수 있습니다. 다만 출처를 표시해 주시면 감사하겠습니다.

다음 자료는 본 라이선스의 적용 대상이 아닙니다.

* 외부에서 제공받은 데이터셋
* 공개 데이터셋 및 오픈소스 프로젝트
* 각 데이터 제공자가 별도의 라이선스를 명시한 자료

이러한 자료의 이용 조건은 해당 데이터 제공자의 라이선스를 따릅니다. 관련 출처와 라이선스 정보는 책 또는 노트북의 출처에서 확인할 수 있습니다.

본 저장소의 코드와 자료는 교육 목적으로 제공되며, 사용으로 인해 발생하는 문제에 대해서는 책임을 지지 않습니다.
